# Project Handover & Issue Analysis

## 1. Project Overview: CyberViewer-Cyto
**CyberViewer-Cyto** is a graph visualization tool designed to render specialized Cyber Security Attack Graphs. It is built using **React**, **TypeScript**, and **Cytoscape.js**.

### Core Architecture
-   **State Management**: `zustand` (Files: `src/core/store/useGraphStore.ts`).
-   **Graph Engine**: `cytoscape.js` (Canvas rendering).
-   **Layout Engine**: `cytoscape-dagre` (Hierarchical auto-layout).
-   **Data Input**: JSON files (Schema: `docs/llm-prompt-json-only.md`) generated by LLMs.
-   **Key Features**:
    -   **Compound Nodes**: Use of Cytoscape "Parent" nodes to represent trust boundaries (Network, Machine, etc.).
    -   **Time-Travel Debugging**: Step-by-step animation of attack paths using the `currentStep` slider.

## 2. The Current Issue: "Container Icon Alignment"

### The Requirement
The Product Owner requires a specific visual layout for Container Headers:
1.  **Container Title**: Must be **Centered** horizontally.
2.  **Container Icon**: Must be an **SVG** (e.g., `attacker.svg`, `cloud.svg`).
3.  **Placement**: The Icon must be **appended** (or prepended) immediately next to the Title.
    -   *Visual Goal*: `[ Dragon Icon ] [ Attacker Space Title ]` grouped together in the center.
4.  **Constraint**: They must not overlap, and they must stay centered regardless of the string length.

### The Technical Limitation (Why it failed)
**Cytoscape.js** separates rendering into discrete layers that do not share layout context (like Flexbox does in HTML):
1.  **Label Layer**: The text is rendered based on `text-halign` and `text-valign`.
2.  **Background Image Layer**: The SVG is rendered based on `background-position-x` / `y`.

**The Conflict:**
-   You cannot define a relationship like "Draw Background Image 5px left of the Text Label".
-   You can only position using **Absolute** or **Percentage** values relative to the *Node Body* (the box), not the text.
-   **Drift**: Since the text length varies ("LAN" vs "Corporate Secure Network"), the center point of the text shifts. A fixed `%` or `pixel` position for the icon will inevitably lead to either a **Gap** or an **Overlap** on different nodes.

### Failed Approaches (To avoid retrying)
1.  **Padding & Margins**: Attempted to push the title with `text-margin-x` and place the icon in the gap.
    -   *Failure*: Dynamic text widths broke the spacing.
2.  **Tab Style (Top Outside)**: Attempted to move both title and icon *above* the container (`text-margin-y: -20px`).
    -   *Failure*: Cytoscape clips background images to the node bounds. The icon disappears or gets cut off if moved outside the border.
3.  **Emoji Injection**: Suggestion to replace SVGs with Emojis (e.g., 🐉) inside the text string.
    -   *Rejected*: User strictly requires specific SVG assets (`public/assets/icons/`), not generic emojis.

## 3. Solution: Custom Canvas Rendering (IMPLEMENTED)

The "Centered Icon + Text" requirement has been **solved** using a custom canvas layer.

### Implementation Details

**File:** `src/ui/features/GraphCanvas/ContainerHeaderRenderer.ts`

The solution uses `cytoscape-canvas` to bypass Cytoscape's stylesheet limitations:

1.  **Canvas Layer**: Creates a canvas layer above nodes (`zIndex: 1`) via `cy.cyCanvas()`.
2.  **Icon Preloading**: Loads container SVG icons as `HTMLImageElement` objects with deduplication cache.
3.  **Centering Algorithm**:
    ```typescript
    centerX = boundingBox.x1 + boundingBox.w / 2;
    totalWidth = iconWidth + gap + textWidth;
    startX = centerX - totalWidth / 2;
    ```
4.  **Position**: Headers render **above** the container (not inside), using `headerY = bb.y1 - HEADER_Y_OFFSET`.
5.  **Theme Integration**: Colors imported from `THEME_COLORS` in `cytoscape-theme.ts` for consistency.

### Key Files
| File | Purpose |
|------|---------|
| `ContainerHeaderRenderer.ts` | Canvas layer, icon cache, draw logic |
| `cytoscape-theme.ts` | Exports `THEME_COLORS`, disables native label/icon for `:parent[iconPath]` |
| `GraphCanvas.tsx` | Initializes layer, triggers preload on `layoutstop` event |

### Timing
Icon preloading and initial render are triggered by the `layoutstop` event (not setTimeout), ensuring headers draw only after layout animation completes (500ms).
